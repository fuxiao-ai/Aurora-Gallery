# Lap 功能借鉴与实施

日期：2026-09-25。

参考 [Lap 项目](https://github.com/julyx10/lap) 的功能说明、前端组件划分及 [MediaViewer](https://github.com/julyx10/lap/blob/main/src-vite/src/components/MediaViewer.vue) 的对比视口交互。Lap 使用 Tauri/Rust 与 Vue；本项目使用 Electron 与原生 JavaScript，因此按本项目结构独立实现，没有引入 Lap 源码或依赖。

## 功能取舍

| 方向 | 本项目情况与安排 |
| --- | --- |
| 2–4 图对比、联动视口 | 本轮新增，复用已有媒体服务，无数据库迁移 |
| 智能相册 | 后续可保存筛选规则；需要统一桌面/Web 查询规则与持久化协议 |
| 评分、挑选/拒绝标记 | 后续可扩展现有收藏能力；需要新增元数据、筛选索引与批量写入接口 |
| RAW 配对、Live Photo | 需要先定义复合资源关系及文件操作语义，再处理扫描与播放 |
| 语义搜索 | 已新增 SigLIP 2 本地多语言图文检索，详见 local-ai-search.md |
| 人脸识别与人物分组 | 已新增 YuNet + SFace 本地检测、分组、命名、合并及纠正，详见 people-groups.md |
| 地图 | 涉及地图来源及交互设计，留待专项设计 |

## 已实现：图片对比

1. 打开图片预览，点击收藏旁的「加入对比」。
2. 切换图片、目录或页面继续加入，候选栏最多保留 4 张；候选不跨应用重启或页面刷新保存。
3. 加入至少 2 张后点击「开始对比」。桌面宽屏采用两列，3–4 张排列两行；窄屏采用可滚动纵向排列。
4. 滑块控制 1–4 倍相对于适应窗口尺寸的同步缩放，放大后拖动可同步平移。「适应窗口」重置缩放和平移。
5. 可以单独移除候选或全部清空。对比窗口关闭后保留候选；不足 2 张时自动退出对比。

支持中英文文案（跟随页面 lang）、Esc 关闭、原生模态焦点管理和加载失败提示。打开对比会关闭原预览并停止幻灯片。仅支持静态图片，图片通过既有 desktop photo 协议或 Web preview-image 接口读取；Web 使用预览图，因此不是原始像素级鉴定工具。

共享实现为 `src/web/js/photo-compare.js` 和 `src/web/css/photo-compare.css`，两端 app 仅提供当前图片与媒体 URL。候选只存最多 4 项元数据，打开窗口才创建图片元素，关闭释放图片来源。文件名使用 textContent/alt，避免作为 HTML 注入。Web 静态资源沿用现有认证边界，并更新 Service Worker 缓存版本。

## 验证范围

`scripts/compare-regression.js` 覆盖重复选择、容量限制、视频拒绝、移除后补入、真实控制器的模拟 DOM 测试（打开/关闭、缩放和平移同步、加载失败、图片资源释放）。加入 `npm test`，现在共有 6 个回归脚本。

模拟 DOM 验证不等于浏览器渲染验收。此前本地预览被浏览器安全策略阻止，本轮未绕过该限制；实际窗口截图、触摸设备及 RAW 实图仍待人工验收。重启桌面应用或刷新 Web 后使用新入口。
