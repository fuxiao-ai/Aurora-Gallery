## 已修复

1. `download-face-models` 指向不存在的脚本。补齐命令，支持 `--help` 和 `--directory`，默认安装到开发应用的数据目录，安装后校验模型。同步修正打包脚本的过期提示。
2. AI / 人脸索引超过 24 小时会被强制终止。取消索引任务的总时限，保留手动停止；下载和交互查询仍有超时保护。使用模拟时钟验证超过两天仍能继续并可取消。
3. 语义索引优先读取缩略图，但损坏时直接记为失败。现在缩略图解码失败会回退原图，两者均失败才计为失败，过程中仍响应取消。
4. 语义索引数据库构造失败时可能遗留打开的连接。异常路径释放来源库和索引库连接，并验证失败后可删除隔离索引文件。
